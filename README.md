## 들어 있는 기능

| | 기능 | 설명 |
|---|---|---|
| 🪙 | 공부 용돈 적립 | 위쪽에 **서준·서윤 잔액이 나란히** 보이고, `[🐵 서준]` / `[🐷 서윤]` 탭으로 각자의 공부 항목을 눌러 동전 팡팡 적립. 항목 추가·수정, 용돈 쓰기, 내역 수정·삭제를 아이별로 따로 관리해요. **`✍️ 지금 기록`에서 누가 적는지 고르면 내역마다 기록한 사람 얼굴·이름 배지가 남아요.** |
| 💌 | 오늘의 한마디 | 엄마·아빠·서준·서윤 **네 줄**에 각각 한 줄씩 적고 **저장 / 삭제**. |
| 🖐️ | 오늘의 할 일 | `[🐵 서준]` / `[🐷 서윤]` 탭으로 각자의 할 일을 체크·추가·삭제. **그 아이의 할 일을 모두 체크하면 하이파이브 축하 화면**이 떠요. |
| 💬 | 가족 채팅방 | 엄마·아빠·서준·서윤 프로필 전환, 귀여운 스티커, **말풍선별 ✕ 삭제**, 상단 **대화 비우기**(확인창). |
| ⏰ | 공부 타이머 & 태블릿 알람 | 10/20/30분·직접 입력 타이머, 태블릿 끄는 시각 알람(효과음 + 전체 화면 안내). |
| 🔒 | 가족 PIN 잠금(선택) | 링크를 아는 사람이 아무나 못 들어오게 4자리 PIN. 기본은 꺼져 있어요. |

## 저장 방식 · 실시간 동기화

- **기본값: 이 브라우저(localStorage)에 저장.** 설정 > "가족 실시간 동기화"가 비어 있으면 각 기기가 따로 저장됩니다.
- **기본 내장 주소:** `https://inbongppu-default-rtdb.asia-southeast1.firebasedatabase.app/` 의 **`junyunFamily/main`** 경로.
  인봉뿌 대시보드(`mongleFamily/main`)와 **경로가 완전히 분리**되어 있어서 두 대시보드의 데이터가 섞이지 않아요.
- 새 기기에서 열면 **먼저 Firebase에서 기존 데이터를 GET** 해서 있으면 그대로 불러오고, 없을 때만 기본값으로 시작합니다.
- Firebase 규칙(테스트용):
  ```json
  { "rules": { "junyunFamily": { ".read": true, ".write": true } } }
  ```
  (공개 규칙이므로 가족 외에 알려지지 않게 URL을 관리하고, 오래 쓸 거라면 인증 규칙으로 바꾸는 것을 권장합니다.)
- PIN은 **그 기기에서만** 쓰는 잠금이라 동기화로 덮어쓰지 않습니다(Firebase에 PIN이 없거나 달라도 잠기지 않도록).
- 태블릿 끄기 알람은 **대시보드 화면을 켜둔 동안** 울립니다(브라우저 정책상 화면을 닫으면 울리지 않아요).

